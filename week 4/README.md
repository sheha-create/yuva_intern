# TaskFlow: Performance + Accessibility

A lightweight, responsive task manager built with semantic HTML, CSS, and plain JavaScript.

## Files
- `index.html` — semantic page structure and accessible form/landmarks
- `styles.css` — responsive styling, theme tokens, reduced-motion and forced-colors support
- `script.js` — task interactions and accessible state updates
- `Performance_Accessibility_Report.md` — full report and testing plan
- `Performance_Accessibility_Report.pdf` — PDF copy of the report

## Run
Open `index.html` in a modern browser. No installation or build step is required.

## Important
Tasks are kept in memory and reset when the page reloads. Run Lighthouse and WAVE/axe on your own browser/deployed copy if your submission requires measured audit scores. The report does not invent test scores.
